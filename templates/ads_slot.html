Deliberately explicit rather than relying on AdSense Auto ads: auto-placement injects units wherever it likes, including anchor/overlay ads docked to the viewport bottom -- which land directly on top of .sticky-share-bar and .dash-fab (both position:fixed; bottom:1.25rem). Auto ads should stay OFF in the AdSense dashboard; these named slots are the only placements. Reserving height matters for more than looks: an ad popping in and pushing content down is layout shift, which Core Web Vitals measures and Google ranks on -- self-defeating on a site whose whole plan is SEO traffic. A slot renders only once site.adsense_slots gives its name a non-empty ad unit ID. Before that -- notably while the account is still under review -- the loader script ships but no unit is drawn, so no page shows an empty "Advertisement" frame that can never fill.
